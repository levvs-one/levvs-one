# levvs-one

I build practical software where networking, desktop UX, and automation meet.

My public work is focused on reproducible behavior: explicit constraints, tests where they matter, traceable sources, and releases that another person can inspect or repeat.

## Selected work

### [Sora](https://github.com/levvs-one/sora-client)

A Windows proxy and VPN client focused on a simple interface and compatibility from Windows 7 through Windows 11. Sora builds on v2rayN 5.39 and keeps its upstream lineage and third-party notices explicit.

`C#` · `PowerShell` · `Inno Setup` · `GPL-3.0`

### [Agentic Web Signals](https://github.com/levvs-one/agentic-web-signals)

A reproducible field study of how websites expose `robots.txt`, `llms.txt v2`, Markdown discovery, and content-use signals to AI agents. The first release includes a declared sample, bounded collector, tests, an immutable JSONL snapshot, and a sourced report.

`Python` · `web research` · `datasets` · `MIT`
